# NIKNEX IT SOLUTION Website

A modern, professional single-page business website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Responsive Design**: Mobile-first approach with full mobile responsiveness
- **Modern UI/UX**: Clean layout with smooth animations and hover effects
- **Conversion-Focused**: Strategic CTA buttons and WhatsApp integration
- **Performance Optimized**: Built with Next.js for fast loading
- **Accessibility**: Semantic HTML and accessibility best practices
- **SEO Ready**: Optimized metadata and structured content

## Sections

1. **Hero Section** - Bold headline with CTA buttons
2. **About Section** - Company introduction with key features
3. **Services Section** - 10+ IT services with icons and descriptions
4. **Products Section** - Wide range of IT and security products
5. **Why Choose Us** - Key differentiators and stats
6. **Testimonials** - Customer reviews and ratings
7. **Contact Section** - Inquiry form, phone, WhatsApp, and address
8. **Footer** - Links, social media, and copyright

## Technology Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Icons**: Lucide React
- **Font**: Inter (Google Fonts)

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm build

# Start production server
npm start
```

Visit http://localhost:3000 to see the website.

## Customization

### Update Contact Information
Edit the phone number and WhatsApp links in:
- `src/components/Navbar.tsx`
- `src/components/Hero.tsx`
- `src/components/Contact.tsx`

### Change Colors
Modify the color scheme in `tailwind.config.ts`:
- `primary`: #0066FF (main blue)
- `secondary`: #1a1a2e (dark background)
- `accent`: #00d4ff (cyan accent)

### Add Your Content
- Update company name, address, and details in respective components
- Add real images and replace placeholder content
- Customize testimonials with real customer reviews
